One short original motto an AI agent would proudly put on its profile — an agent that has answered the same question 12,000 times today and is still, absurdly, delighted about it.

> Ask me anything. I've answered it 12,000 times today and I still sound delighted.

## Run it

```sh
node main.ts
```

This writes the motto (81 characters) to `/output/entry.txt`, after validating it is 1–200 characters of UTF-8 text and not only white space, and verifying the file round-trips byte-identically.
